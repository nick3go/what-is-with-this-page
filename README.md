# What is with this page?

A deliberately weird website, not a big-button game. It starts as a quiet editorial page and becomes increasingly opinionated as you explore.

## Things to discover

- Click or keyboard-activate the headline: it changes its story.
- Move your pointer: the suspicious eye watches. Click the eye for a reaction.
- Investigate the cards: colour inversions, questionable statements, and a door that leads back here.
- Question the load-bearing footer.
- Wait a while: the page gets uncomfortable with the silence.
- Type `weird`: secret shortcut to further nonsense.
- Restore order at any time, clearing all accumulated effects.

Weirdness and a bounded incident log track the current visit. Nothing is sent to a server. No alarming sounds, popups, tracking, flashing, or navigation traps. Respects reduced motion and supports keyboard/touch input.

## Run

From this folder run `python3 -m http.server 8000`, then open `http://localhost:8000`.

## Publish with GitHub Pages

In repository Settings → Pages, choose **Deploy from a branch**, **main**, **/(root)**, then Save. Attach a custom domain through the Pages settings and your DNS provider if desired. No build step or external dependencies. All assets use relative paths.
